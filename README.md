# NMAMIT Notes Hub

A student-run resource hub for NMAM Institute of Technology (Nitte) IT students. Provides free, organized study materials for all first-year courses (2024-2025 academic year).

## Features

- **Two semesters** – Physics Cycle & Chemistry Cycle
- **17+ subjects** with unit-wise notes, PDFs, video links, question banks
- **Course search** – filter by name or course code
- **Responsive design** – works on mobile, tablet, desktop
- **32 themes** – customizable appearance via CSS variables
- **Update log**, FAQ, feedback form, and contribution support

## Subjects Covered

**Physics Cycle:** Basic Electronics, Calculus, Constitution of India, Cyber Security, Quantum Computing & Modern Physics, Problem Solving through Programming, Biology for Engineers, Environmental Studies, Technical English

**Chemistry Cycle:** Applied Digital Logic Design, Basic Electrical Engineering, Discrete Math, Engineering Visualization, Python Programming, Materials Chemistry, Constitution of India, Technical English

## Usage

1. Clone: `git clone https://github.com/LnAigal/NMAMIT-Notes-Hub`
2. Open `index.html` in a browser
